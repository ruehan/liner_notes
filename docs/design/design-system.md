## 1. 레퍼런스 분석 — omrimalka.art

### 1.1 전체 컨셉

사이트는 "스크롤하는 홈페이지"가 아니라 **드래그로 패닝하는 벽(wall)** 이다.

- 전체 화면 고정 스테이지 위에 작업 카드들이 물리적으로 흩뿌려져 있다.
- 사용자는 마우스 드래그(또는 터치 스와이프)로 벽을 밀며 탐험한다.
- 카드마다 미세한 회전(`--lean`)이 걸려 있어 "정렬된 그리드"가 아니라
  **손으로 붙인 스티커·포스터**처럼 보인다.
- 주변은 비네트(가장자리 어둡게)로 감싸 시선이 중앙에 머무른다.
- 반대편엔 "catalog"라는 **조용한 인덱스 모드**가 있어, 한 화면에 한 프로젝트씩
  크로스페이드되는 정적인 열람을 제공한다. 자극적 피드와 정적 인덱스의 이중 구조.

감성 키워드: 아날로그 카탈로그, 손맛(미세 회전·비틀린 버튼), 암실, 형광 옐로 액센트,
타이프 중심, 절제된 크롬(UI 장식을 최소화하고 콘텐츠를 벽처럼 채움).

### 1.2 컬러 토큰

| 토큰 | 값 | 쓰임 |
|---|---|---|
| `--bg` | `#0b0b0c` | 배경 (거의 검정, 살짝 웜) |
| `--fg` | `#f2f0ec` | 전경 텍스트 (웜 오프화이트) |
| `--fg-dim` | `#8b8a86` | 보조 텍스트 |
| `--fg-faint` | `#55544f` | 희미한 텍스트 |
| `--accent` | `#ffe603` | 액센트 (형광 옐로 — 다이얼, 강조, CTA) |
| `--line` | `rgba(242,240,236,.12)` | 구분선 |
| 시트 배경 예시 | `#8d9b3c` (올리브) / `#c9c4b8` (종이) | 카테고리별 "카탈로그 시트" 배경 |
| 시트 잉크 예시 | `#403d1f` | 시트 배경 위의 텍스트 |

원칙: 배경은 암실처럼 어둡고, 크롬(버튼·필터)은 종이처럼 밝은 오프화이트,
포인트는 한 가지 형광색만. 상세 화면은 카테고리마다 시트 색이 바뀌며
시트 색과 잉크 색은 세트(`--sheet-bg` / `--sheet-ink`)로 관리된다.

### 1.3 타이포그래피

- 폰트: 커스텀 산세리프(RAG Sans, woff2 두 웨이트 regular/bold), 폴백 Helvetica/Arial.
  전체 모노/산세리프 구분을 없애고 **한 서체로 통일**(`--mono: var(--sans)`).
- 스케일(뷰포트 반응형 `clamp()`):

| 토큰 | 크기 | 쓰임 |
|---|---|---|
| `--t-micro` | 9.5–11px | 카드 구석 캡션, 카운터 |
| `--t-label` | 11–13px | 메타 라벨, 태그 |
| `--t-ui` | 12–15px | 버튼, UI |
| `--t-body` | 12.5–15.5px | 본문 |
| `--t-lead` | 14–18px | 리드 문장 |
| `--t-display` | 26–44px | 큰 제목 |
| `--t-chrome` | 15–20px | HUD 크롬 텍스트 |
| `--t-mast` | 20–29px | 로고, readout 제목 |

- 규칙:
  - 마이크로 라벨: 자간 `+8~12%`, 대문자, 굵기 600 — "계기판 판독값" 느낌.
  - 디스플레이: 자간 `-3.5%`, 줄높이 1.02 — 딱 붙는 대형 타이틀.
  - 링크: 밑줄(1.5px → hover 3px) 또는 `border-bottom: 2px`, 끝에 `↗`.
  - 숫자는 `tabular-nums`.

### 1.4 레이아웃·공간

- `html, body { overflow: hidden }` — 페이지 스크롤이 없다. 세계 자체가 캔버스.
- `#stage > #world`: fixed 스테이지 위에서 transform으로 패닝하는 월드.
  셀은 `position: absolute`, 개별 회전, `clip-path` 트랜지션으로 열림/닫힘.
- HUD는 화면 가장자리에 떠 있는 고정 크롬:
  - 좌상단: 로고(아이콘+워드마크).
  - 중앙 상단: 필터 슬래브.
  - 우상단: about.
  - 좌하단: readout(현재 바라보는 대상의 제목·메타, 폴인/폴아웃).
  - 우중앙: shuffle 버튼.
- 비네트 레이어: 상하 리니어 그라디언트 + 라디얼로 가장자리를 어둡게.
- 반경(rounded)은 보수적: UI 4px, 미디어 10px, 셀 18px. 대체로 각진 종이 느낌.

### 1.5 컴포넌트 인벤토리

| 컴포넌트 | 특징 |
|---|---|
| 필터 슬래브 | 화이트 배경에 버튼 4개(all/direction/motion/design), 활성 버튼 뒤로 옐로 다이얼이 스프링으로 슬라이드. 슬래브 전체가 미세 기울기(`--lean`) |
| 버튼 크롬 | 화이트 배경 + 어두운 잉크, hover 시 `scale(1.07)`, 각각 다른 미세 회전값(-2.1deg, 1.4deg, -0.9deg…)으로 삐뚤게 부착 |
| readout | 좌하단, 현재 셀 제목(마스트 크기) + 메타(라벨 크기), 텍스트 섀도우 |
| 벽의 셀 | 이미지/비디오, `object-fit: cover`, 로딩 전까지 `opacity: 0 → 1` 페이드 |
| 상세 시트 | 카테고리색 그라운드(`clip-path` 사각형으로 코너핀 가능), 좌측 텍스트 블록(제목·태그 칩·설명·역할·링크), 우측 3D 릴 |
| 3D 릴 | `perspective: 1500px`, 링 위에 카드들이 회전하는 카루셀. 앞면 카드는 `cursor: zoom-in`, 그림자 강화 |
| 태그 칩 | 화이트 칩 + 미세 회전, hover 시 살짝 떠오름 |
| 샷 뷰어 | 개별 작품 전체 화면, prev/next 체브론, 모노 대문자 캡션 |
| 카탈로그 | 한 화면 한 프로젝트, `scroll-snap`, 배경 미디어 크로스페이드(.48s) + 스케일 settle(.9s), 거대 타이틀(clamp 38–104px) |
| About | 종이색(`#c9c4b8`) 시트, 2열(42ch 텍스트 + 미디어 더미) |
| 부팅 화면 | 마크 3개가 `steps(1)` 지글지글 애니메이션 + 1px 프로그레스 바 후 페이드아웃 |

### 1.6 모션 스펙

| 토큰 | 값 | 쓰임 |
|---|---|---|
| `--dur-1` | .14s | hover, 프레스 |
| `--dur-2` | .26s | UI 폴인/아웃 |
| `--dur-3` | .42s | 화면 전환, 다이얼 이동 |
| `--dur-4` | .62s | 부팅 페이드, 시트 그라운드 |
| `--ease-out` | `cubic-bezier(.16,1,.3,1)` | 기본 출구 (expo-out) |
| `--ease-in-out` | `cubic-bezier(.65,0,.35,1)` | 대칭 이동 |
| `--ease-spring` | `cubic-bezier(.34,1.42,.64,1)` | 오버슛 스프링 (다이얼, near 셀, 버튼) |

- 열림 연출은 항상 지름길로, 닫힘은 빠르게(.1s).
- 커스텀 커서 레이어를 별도 `pointer-events: none` 레이어로 분리.
- `prefers-reduced-motion` 시 모든 애니메이션/트랜지션을 0.01ms로 강제, 셀 비디오 숨김.
- 포커스 링: `outline: 2px solid var(--accent); outline-offset: 3px`.

## 2. 우리 프로젝트 적용 — 음악 사전

우리 프로젝트(**liner notes**): 직접 고른 음악들을 보여주는 **플레이리스트이자 개인 음악 아카이브**.
대외 공개 포트폴리오. 원작의 "작품 벽" 구조가 "선곡 컬렉션"과 1:1로 대응한다.

### 2.1 콘텐츠 매핑

| 원작 | 우리 프로젝트 |
|---|---|
| 벽의 셀 (작품 포스터) | 트랙 목록 카드 — 절차적 커버아트 + 카탈로그 번호 + 제목/앨범 라벨 |
| 필터 all / direction / motion / design | 장르 또는 무드 필터 (예: all / ambient / jazz / electronic … 4개 내외로 유지) |
| 상세 시트 (작업 설명) | **사전 항목** — 곡 제목(대형 타이틀), 아티스트, 연도, 설명(왜 이 곡을 골랐는가), 태그(장르·무드·장면), 외부 링크(뮤비·스트리밍 ↗) |
| 3D 릴 (작업 조각들) | 종이 액자 + 뒷장 겹침으로 대체 (절차 생성 커버아트 스택) |
| shuffle 버튼 ("wander") | "랜덤 청취" — 벽의 아무 곡 앞으로 이동, 가능하면 미리듣기 시작 |
| readout | 바라보는 트랙의 제목 · 아티스트 · 연도 |
| 카탈로그 모드 | 조용한 트랙 인덱스 — 한 화면 한 항목(scroll-snap), 검색·순서대로 듣기, 항목 클릭 시 상세 모달 |
| About | 아카이브 소개 · 조작 안내(드래그/R/I/♥/Esc) 시트 |
| 시트 카테고리 컬러 | 장르/무드별 시트 색 세트 (배경+잉크 토큰 쌍) |

### 2.2 아이디어는 상속, 비주얼은 우리 것 — "Archive Room"

원작에서 **구조적 아이디어만** 가져오고 색상·서체·모티프는 우리 것으로 재정의한다.

> 변천: v1 "night lexicon"(밤 인디고 + 코럴)은 음악 아카이브라는 컨셉 대비
> 정체성이 약하다는 평가로 폐기. v2 **Archive Room**(개인 음악 아카이브 룸)으로 전환.
> 상세: docs/decisions/0002.

**상속하는 아이디어**

- 드래그 패닝 벽 + 미세 회전으로 흩뿌려진 카드.
- 화면 가장자리의 얇은 HUD 크롬(로고·필터·about)과 readout.
- 전체 화면 상세 + shuffle + (향후) 조용한 인덱스 모드.
- 모션 철학(expo-out + 스프링, 열림은 부드럽게 닫힘은 빠르게),
  `prefers-reduced-motion` 전면 지원, 포커스 링은 액센트색.

**우리만의 비주얼 — 기록 보관실**

- **색**: 어두운 벽 대신 **오래된 종이** 배경(`#e9e1cd`), 벽면은 그보다 한 톤 어두운
  카드보드(`#e2d8c0`)에 점 그리드. 텍스트는 진한 갈색 잉크(`#221c12`).
  단일 액센트는 **도장 레드**(`#c8372d`) — 카탈로그 번호, 도장, 진행 바에만 사용.
- **서체**: **Gmarket Sans** 단일 패밀리. Light·Medium·Bold의 세 굵기를 제목,
  UI, 기록 메타에 일관되게 사용한다.
- **아카이브 모티프**: 카탈로그 번호(`LNR-001`), 장르 테이프 칩, 도장(스탬프),
  점선 구분, 카드 위 마스킹 테이프. 발음 기호(`/ˈdʒæz/`)는 사전 모티프로 유지.
- **카드(셀)**: 색 면 대신 **목록 카드** — 절차적 커버아트(SVG 패턴) +
  카탈로그 번호 + 세리프 제목 + 앨범·길이 메타. 카드 하단은 종이 라벨.
- **절차적 커버아트**: 트랙 id 시드로 링(음반 그루브)·바·파형·도트 중 하나 생성.
  장르 테이프 색(bg) 위 잉크 색 패턴 + 도장 레드 포인트. 이미지 자산 불필요.
- **상세 화면**: 가로 ruled 라인 종이 위에 기록 카드. 우측에 종이 액자 속
  커버아트(뒷장 액자 하나 겹침), 우상단 도장(`LNR-### · FILED <연도>`).
- **필터**: 모노 대문자 탭 + 도장 레드 슬라이딩 밑줄 + 항목 수 sup.
- **장르 테이프 컬러**: 뮤트 3종 — 아카이브 블루(#3d5a80), 시에나(#a8622d),
  모스 그린(#5c7045). 각각 짝색 잉크를 가짐.

### 2.3 음악용으로 추가·확장할 요소

- **플레이 상태 표시**: 셀에 재생 중일 때만 미세 표시(작은 재생 삼각 또는 진행 막대).
  벽은 기본적으로 조용한 포스터 집합으로 유지하고, 소리는 사용자가 명시적으로
  재생을 시작할 때만 나온다(autoplay 금지).
- **미리듣기**: 상세 시트에서 저자극 미리듣기(외부 임베드 또는 자체 오디오).
  원작의 yt-play/ig-play 버튼(커버 이미지 위 원형 재생 버튼) 패턴 그대로 차용.
- **사전적 메타**: 각 트랙에 번호(index), 길이, 연도를 마이크로 라벨로 부착 —
  "책의 표제" 느낌을 강화.
- **플레이리스트 모드(선택)**: 카탈로그 모드에 "순서대로 듣기"를 더해
  인덱스가 곧 플레이리스트가 되도록.
- **절제**: 파형 이퀄라이저 같은 과한 오디오 비주얼은 원작의 절제된 톤과 충돌하므로
  도입 시 매우 작고 정적인 형태로만.

### 2.4 화면 플로우

```
부팅 화면 → 벽 (HUD: 로고 · 필터 · index · about) — 벽은 무한 패닝(토러스 랩)
  ├─ 셀 호버 → readout (카탈로그 번호 · 제목 · 아티스트 · 앨범)
  ├─ 셀 클릭 → 상세 시트 (기록 카드) ←─ 종이 액자 · 도장 · prev/next · ↗ 링크
  ├─ ♥ 수집 → localStorage 저장, 카탈로그 인덱스에 반영
  ├─ shuffle (R) → 랜덤 곡으로 점프 (가장 가까운 복사본으로)
  ├─ index (I) → 카탈로그 인덱스 (검색 · 순서대로 듣기 · 항목 클릭 시 상세 모달)
  └─ about → 아카이브 소개 시트
```

벽은 한 방향으로 끝없이 이어진다. 월드(W×H)를 타일로 반복 렌더하고
뷰포트와 교차하는 타일만 그린다(shared/lib `tileOffsets`). 카메라는 클램프 없이
자유 이동하며, 점프 셔플은 현재 카메라에서 가장 가까운 복사본으로 이동한다.

**무한 항목**: 각 타일은 자신만의 트랙셋을 가진다. 홈 타일 `(0,0)`은 큐레이션된
실제 선곡을 쓰고, 그 외 타일은 시드 기반 절차 생성(`entities/track` generator)이
곡·아티스트·앨범·정의문을 만들어 벽이 끝없이 새 항목으로 채워진다. 카탈로그
번호는 타일 좌표를 인코딩한다(홈 `LNR-001`, 그 외 `LNR-<k>.<m>-<nn>`).

**카탈로그 인덱스**: 벽의 반대편, 조용한 열람 모드. 한 화면 한 항목
(scroll-snap), giant 세리프 제목 + 유령 번호, 상단 바에 검색(제목·아티스트·
카탈로그 번호)과 "순서대로 듣기"(첫 항목부터 상세 prev/next로 이어 듣기).
인덱스 구성 = 홈 타일 선곡 + 수집한 항목. 항목 클릭은 벽으로 돌아가는 대신
곧장 상세 모달을 연다.

**수집(큐레이션)**: 카드·상세의 ♥ 버튼으로 수집. localStorage에 타일 좌표 키
(`k,m:i`)로 저장하고 절차 생성이 결정적이므로 재방문해도 같은 기록이다.
HUD index 버튼의 카운트는 인덱스 항목 수.

**About**: 아카이브 소개 + 조작 안내(드래그/R/I/♥/Esc) 시트.

## 3. 구현 참고

### 기술 스택 권고

- React + TypeScript (CONVENTIONS의 FSD 구조 적용).
- 벽 패닝은 가벼운 커스텀 레이어(transform + pointer events)로 충분.
  3D 릴은 CSS `transform-style: preserve-3d`로 구현 가능(원작도 DOM 기반).
- 트랜지션 위주 연출이므로 추가 애니메이션 라이브러리는 필요하면 마지막에 검토.

### 원작이 지키는 원칙 (우리도 지킬 것)

- 이미지 로딩 전 `opacity: 0`, 로드 완료 후 페이드인.
- 폰트 preload + `font-display: swap`.
- 스크립트는 `load` 이후 지연 로딩(무거운 외부 스크립트 금지).
- `touch-action` 명시적 관리(벽은 none, 상세 내 스크롤은 pan-y).
- `prefers-reduced-motion` 시 모션 전면 비활성.
- 키보드 접근: Escape 닫기, 포커스 링, dialog role/tabindex.
- 셀에 `contain: layout style paint`로 렌더 비용 제한.
