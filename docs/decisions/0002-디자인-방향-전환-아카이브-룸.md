# 0002. 디자인 방향 전환 — night lexicon → Archive Room

- 상태: 채택
- 날짜: 2026-08-19

## 배경

v1 구현(night lexicon: 밤 인디고 배경 + 코럴 액센트 + 이니셜 플레이스홀더)이
"음악 아카이브"라는 프로젝트 컨셉에 비해 밋밋하고 범용적으로 보인다는 평가.
디자인 시스템 자체의 전환이 필요했다.

## 결정

v2 방향 **Archive Room**(개인 기록 보관실)으로 전환한다.

- 팔레트: 어둠 → 오래된 종이(라이트). 배경 #e9e1cd, 잉크 #221c12,
  단일 액센트 도장 레드 #c8372d.
- 서체 역할 분리: Fraunces(디스플레이 세리프) / Space Grotesk(UI) /
  Space Mono(기록 메타). @fontsource로 셀프호스트.
- 셀을 색 면+이니셜에서 **목록 카드**로 교체: 절차적 SVG 커버아트
  (트랙 id 시드 — 링·바·파형·도트 4패턴), 카탈로그 번호(NLX-###),
  장르 테이프 칩, 앨범·길이 메타.
- 상세 화면을 장르색 시트에서 **ruled 종이 위 기록 카드**로 교체:
  도장(NLX-### · FILED 연도), 종이 액자(커버아트 + 뒷장 겹침),
  dl 메타 테이블(album/label/year/length).
- 로고: 회전 디스크 → 도장(스탬프) 마크. 트랙 데이터에 album·label 필드 추가.

## 이유와 대안

- 대안 A(다크 유지 + 커버아트 강화): 개선은 되지만 "아카이브" 기호가 약하다.
- 대안 B(라이트 전환): 종이·도장·세리프가 아카이브를 가장 직접적으로 전달하고,
  기존 다크 포트폴리오들과 차별화된다. 접근성(명도 대비)도 유리.
- 절차적 커버아트는 이미지 자산·저작권 문제를 피하면서 카드마다 고유 얼굴을 준다.
