# 0004. 무한 아카이브 — 절차 생성 트랙 항목

- 상태: 채택
- 날짜: 2026-08-19

## 배경

무한 패닝 벽을 만들었지만, 12곡이 반복될 뿐이었다. 사용자는 "계속 이동하면
계속 새로운 항목이 나와야 완성"이라고 정의했다. 개인 선곡은 유한하므로
무한한 콘텐츠를 제공하는 방식을 결정해야 했다.

## 결정

타일 단위 절차 생성으로 아카이브를 무한화한다.

- 홈 타일 `(0,0)`은 시드 없이 호출하면 큐레이션된 기본 선곡(TRACKS)을 사용한다.
  실제 화면은 새로고침마다 만든 세션 시드를 모든 타일에 적용해 홈을 포함한 새 앨범
  컬렉션을 보여 준다.
- 그 외 타일은 `generateTileTracks(k, m)`이 타일 시드로 12곡을 생성:
  장르어 뱅크 조합 제목, 가상 아티스트·레이블, 연도·길이, 한국어 정의문.
- 화면에는 `generateTileAlbums(k, m)`이 각 대표 곡을 앨범으로 감싸 12장의 앨범
  카드로 보여 준다. 앨범 상세에는 대표 곡을 포함한 결정적 수록곡 목록이 열린다.
- 카탈로그 번호에 타일 좌표를 인코딩해 위치가 기록에 남는다
  (홈 `LNR-001` / 그 외 `LNR-<k>.<m>-<nn>`).
- 생성은 세션 안에서 결정적(같은 타일 = 같은 항목)이라 이동 후 돌아와도 기록이
  유지된다. 수집 키는 세션 시드를 함께 저장해 새로고침 뒤에도 해당 앨범을 복원한다.

## 이유와 대안

- 대안 A(12곡 무한 반복): 끝없이 걸을 수 있지만 내용이 같아 "아카이브"가 아니다.
- 대안 B(외부 음원 API로 무한 실데이터): 저작권·키 관리·의존성이 늘고
  포트폴리오 정적 배포와 충돌한다.
- 절차 생성은 자산 없이 무한 콘텐츠를 보장하고, 생성 항목은 나중에 실제
  선곡 데이터로 교체 가능한 플레이스홀더 역할도 한다.

## 영향

- 상세 시트·readout·필터 카운트(보이는 타일 기준)가 무한 앨범과 호환된다.
- 실선곡이 늘면 홈 타일 확장 또는 새 "큐레이션 타일" 지정 방식으로 교체 가능.
- 생성 콘텐츠임을 About 등에서 명시하는 것을 검토할 것.
